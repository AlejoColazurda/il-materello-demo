Integración con Fudo Gastronomía

Conectá la Carta Virtual con el sistema de punto de venta (POS) y comanderas del local.

API Fudo v1 Conectada

¿Cómo funciona la integración con Fudo?

1
Sincronización de Catálogo

La carta virtual descarga automáticamente los platos, categorías y precios configurados en Fudo.

2
Envío Directo de Comandas

Cuando el cliente toca "Enviar Comanda", la app crea la venta en Fudo asignada a la mesa correspondiente.

3
Impresión en Cocina & Facturación

Fudo dispara el ticket físico a la comandera de cocina o barra y deja la mesa abierta para su cobro.
